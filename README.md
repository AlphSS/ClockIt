# ClockIt

A student community platform that helps university students:

- Buy & Sell products (UniMart)
- Find compatible roommates (Roomies)
- Discover student-friendly flats (UniStay)

## Tech Stack

- React
- Node.js
- Express
- Supabase (PostgreSQL)
- Tailwind CSS
- Socket.IO

## Features

- Authentication
- Marketplace
- Roommate Finder
- Flat Listings
- Chat
- Notifications
